Accessibility

We use WCAG 2.2 AA as a guide when updating this directory.

Using the directory

Use the skip link to move to the main content. You can search, open profiles and compare faculty with a keyboard. Press Escape to close a profile and return to the control that opened it.

Report a barrier or ask for another format

If you cannot use part of the directory, use the Haskayne DBA program contact page. Include the page or feature, what happened, and the format that would help. You do not need to share a diagnosis or confidential research information.

External sites and browser-generated printouts may work differently with assistive technology.
